\section{Protocol QV-01: Quantum Vlasov Zero-Sound Extraction}
In the high-frequency limits of liquid $^3$He, Zero-Sound waves propagate collisionlessly. The exact infinite rational series for the continuous base response (Lindhard function) is given by:
\begin{equation}
    \chi_0(z) = \sum_{k=1}^{\infty} \frac{1}{2k+1} z^{2k}
\end{equation}
where $z = \frac{q v_F}{\omega}$. Introducing the Landau interaction parameter $F_0^s$, the Random Phase Approximation (RPA) response is:
\begin{equation}
    \chi_{RPA}(z) = \frac{\chi_0(z)}{1 - F_0^s \chi_0(z)}
\end{equation}
\textit{Update (see RETRACTIONS.md R6/R7): the RPA-driven pole tracking described above as originally
planned was never actually implemented -- an early attempt fed a polynomial into a function expecting
Taylor coefficients and produced meaningless output, and separately violated the exact-arithmetic rule
via a float round-trip. It has been replaced by the following, which is implemented and tested.} Instead
of floating-point numerical integration, the exact diagonal $[M/M]$ Pad\'e approximant of the Landau
zero-sound kernel $\chi(s)$ is computed strictly over $\mathbb{Q}$, and the dispersion relation
$\chi(s) = 1/F_0^s$ is solved exactly as a polynomial root. For strong coupling (e.g. $F_0^s = 93/10$,
$^3$He-like) this gives $s = \sqrt{37/10}\ldots$ at $[1/1]$, agreeing with a 60-digit reference to
$6.8\times10^{-10}$ at $[4/4]$. For weak coupling, no admissible root exists at any order -- the mode is
exponentially close to the particle-hole continuum edge, $s - 1 \simeq 2e^{-2-2/F_0^s}$, and this
negative result is characterised analytically rather than ``tracked into'' the continuum, which the
method cannot do.

\section{Protocol QVE-02: Second-order Volterra response (not an echo -- see RETRACTIONS.md R2)}
